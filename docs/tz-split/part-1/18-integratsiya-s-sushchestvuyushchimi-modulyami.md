##### С расписанием занятий

При создании занятия в таблицу lessons добавляются:

```sql
ALTER TABLE lessons ADD COLUMN room_id UUID REFERENCES rooms(id);
ALTER TABLE lessons ADD COLUMN equipment_booking_ids JSONB; -- IDs из equipment_bookings
• Отмена/перенос занятий, использующих оборудование на ремонте
• Учет времени простоя оборудования в статистике загрузки
```

##### С системой уведомлений

• Уведомления о необходимости ТО оборудования

• Напоминания о бронировании залов

• Предупреждения о конфликтах расписания

• Уведомления о создании новых заявок на ТО

• Напоминания о назначенных работах

• Оповещения о завершении ремонта

##### С модулем отчетности

• Отчеты по затратам на ТО (для внешних подрядчиков)

• Статистика времени простоя оборудования

• Анализ частоты поломок по типам оборудования

Существующая связь сохраняется:

```text
exercises_templates → type_exercis_id → equipment_types (через exercise_type_id)
```
