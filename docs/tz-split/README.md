# ТЗ FitMan — разбивка на разделы

Три исходных `.docx` разбиты на **43 небольших markdown-файла** по структуре документа
(глава → модуль → подраздел). Полный текст сохранён: проверено по абзацам, потерь нет.

## Зачем

Три `.docx` целиком — это ~200 000 символов, то есть **~90–100 тыс. токенов**.
Если грузить их все в чат, контекст съедается моментально, а ответ всё равно нужен
по одному-двум разделам. Теперь достаточно открыть `INDEX.md` и прочитать
1–3 файла по 300–4000 токенов.

## Как пользоваться

1. Откройте [INDEX.md](INDEX.md) — там таблица: файл, раздел, объём.
2. Читайте только нужный файл. Каждый файл самодостаточен: в шапке указано,
   откуда он взят, и есть ссылка назад в индекс.
3. Поиск по всему ТЗ — обычный grep по папке `part-*/`:
   ```powershell
   Select-String -Path 'part-*\*.md' -Pattern 'биоимпеданс'
   ```

## Структура

| Папка | Что внутри |
| --- | --- |
| `part-1/` | Часть 1 — введение, основной функционал, модули (пользователи, сотрудники, группы, здания, оборудование) |
| `part-2/` | Часть 2 — расписание, планы тренировок, онбординг, антропометрия, уведомления, чат, отчётность, нефункциональные требования |
| `part-3/` | Часть 3 — модули Администратор, Клиент, Инструктор, Тренер, Менеджер, Каталоги |
| `_build/split_tz.py` | Скрипт разбиения (перегенерация при правках `.docx`) |

## Перегенерация после правок исходников

```powershell
cd docs\tz-split
python _build\split_tz.py . ..\"Требования ТЗ фитнес-тренинг часть 1.docx" ..\"Требования ТЗ фитнес-тренинг часть 2.docx" ..\"Требования ТЗ фитнес-тренинг часть 3.docx"
```

Скрипт заново создаст файлы и `INDEX.md`. Правки в `.md` при этом потеряются —
если нужно что-то дописывать, лучше держать заметки отдельными файлами.
