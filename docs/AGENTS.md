# Правила работы с документацией

## ТЗ

- Исходники: `Требования ТЗ фитнес-тренинг часть 1..3.docx` — целиком не читать.
- Разбивка: `tz-split/INDEX.md` → `tz-split/part-1|2|3/*.md`. Точка входа — индекс.
- Читайте только файлы по теме задачи (1–3 файла), а не все 43.
- Файлы в `tz-split/part-*/` генерируются скриптом `tz-split/_build/split_tz.py`.
  Правки в них потеряются при перегенерации — заметки держите отдельными файлами.
- После правок `.docx` перегенерируйте разбивку командой из `tz-split/README.md`
  и проверьте, что число абзацев не изменилось.

## Ссылки в ответах

- В чате давайте ссылки относительными путями от рабочей папки (`docs`),
  иначе они не открываются: `tz-split/part-1/09-modul-upravleniya-gruppami.md`.
- Внутри `.md` — только относительные ссылки.

## Тексты

- Пишите по-русски, коротко; термин из ТЗ используйте как в ТЗ.
- Не переписывайте требования «своими словами» без запроса — цитируйте раздел.
