# Миграции БД

Каталог для версионированных SQL-миграций. Применяет их
`backend/bin/migrate.dart`; факт применения хранится в `schema_migrations`.

## Запуск

Из каталога `backend`:

```powershell
dart run bin/migrate.dart
```

Скрипт использует `.env` текущего окружения (`DART_ENV`, по умолчанию `dev`).
Для отдельной тестовой БД создайте локальный env-файл с нужными `DB_*`
и запускайте с соответствующим `DART_ENV`.

## Правила

- Один файл — одна логическая миграция, имя `NNNN_описание.sql`.
- Файлы применяются по порядку имён, один раз.
- Не менять уже применённые файлы: добавляйте новый.
- `audit_log` — append-only; `UPDATE`, `DELETE` и `TRUNCATE` запрещены
  guard-триггером.
- Перед миграцией с изменением данных сделайте резервную копию.
